# JD Analyser 🔍

An AI-powered HR tool that analyzes job descriptions and helps candidates and HR professionals make smarter hiring decisions.

## What it does

- **Structure Analysis** — flags missing sections in a JD (benefits, reporting structure, growth path)
- **Bias Detection** — identifies gendered or exclusionary language with an inclusivity score
- **Keyword Optimization** — shows strong keywords, missing ones, and SEO tips to improve JD visibility
- **Salary Transparency** — checks whether compensation is disclosed and gives recommendations
- **Resume Match Scoring** — paste your resume alongside a JD and get a match percentage, strengths, and gaps to address

## Built with

- React
- Anthropic Claude API (claude-sonnet-4-5)
- CSS-in-JS styling

## How to run locally

1. Clone the repo
2. Run `npm install`
3. Add your Anthropic API key to `src/App.js` where it says `YOUR_API_KEY_HERE`
4. Run `npm start`
5. Open `http://localhost:3000`
